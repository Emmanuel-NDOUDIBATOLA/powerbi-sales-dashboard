# 📊 Sales Performance Dashboard - Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard built using the Sample Superstore dataset.

The objective is to analyze sales performance, profitability, product categories, and customer segments through interactive visualizations.

---

## 🛠️ Tools Used

- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel / CSV
- Git & GitHub

---

## 📂 Dataset

- Sample Superstore Dataset (CSV)

Main attributes:

- Sales
- Profit
- Quantity
- Category
- Sub-Category
- Region
- Segment
- Ship Mode

---

## 📈 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Profit Margin KPI
- Sales by Category
- Profit by Sub-Category
- Interactive slicers:
  - Product Category
  - Region
  - Customer Segment

---

## 🧠 Skills Demonstrated

- Data Import
- Data Cleaning with Power Query
- Data Modeling
- DAX Measures
- Interactive Dashboard Design
- Business Intelligence Reporting
